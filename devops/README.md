# DevOps Folder Guide

- `k8s/` - raw Kubernetes YAML manifests
- `helm/` - Helm chart version of deployment
- `terraform/` - infrastructure provisioning (AWS EC2 starter)
- `ansible/` - configuration management and app deploy
- `monitoring/` - Prometheus + Grafana stack

This folder is intentionally simple and beginner-friendly so it can be explained easily in a college project viva.
